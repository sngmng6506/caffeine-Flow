# 음악 라벨링

신청곡을 자동 라벨링한 뒤 사람이 빠르게 확인·수정하는 관리자 정적 앱이다.

- `/labeling-lab`에서 관리자 sessionStorage 토큰으로 접속한다.
- `/admin/audio-labels`에서 플랫폼·곡별 중복 제거 목록과 서버 집계를 읽는다. AI 필터 OFF·거절 곡과 Spotify 미지원 상태도 포함한다.
- 기본 보기는 자동 분석이 끝난 검토 대상만 보여준다. 대기·실패·미지원 곡은 미검토 전체/전체 보기에서 확인한다.
- 자동 라벨은 이미 DB에 저장되어 있고 입력란에 복원된다. `이대로 확인 · 다음`은 변경 없이 확인하고 다음 곡으로 이동한다. `수정 저장 · 다음`은 최종 라벨을 변경한다. `다음`만 누르면 미검토 상태를 유지한다.
- 매장 정책 승인·거절 선택은 필요 없다. 카페별 정책 골드 판단 API는 별도로 유지한다.
- MAEST 상위 스타일의 평균·최댓값과 구간 수, 기본 특징·추천값을 표시한다. 원본 버튼으로 전체 구간 JSON과 이력 ID를 조회한다. 무드·보컬·악기 미확정도 강제 입력 없이 확인할 수 있다. 이상한 곡은 `곡 듣기`로 원래 플랫폼에서 듣고 수정할 수 있다.
- 분석이나 최종 라벨이 화면 조회 후 바뀌면 409로 저장을 막으며 새로고침 후 다시 검토한다.
- `새로고침`으로 워커 진행 상태를 갱신한다. Spotify는 전체 음원 자동 분석 미지원이다.
- 자동 라벨의 기본 사용 목적은 평가다. 사람 확인·수정값은 자동 분석이 덮어쓰지 않는다.

상태·모델 계약은 [아키텍처](../docs/ARCHITECTURE.md), 입력·출력은 [API](../docs/API.md)를 따른다.
