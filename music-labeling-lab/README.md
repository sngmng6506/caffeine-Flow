# 음악 라벨링

전체 카페의 AI 음악 필터 처리 이력을 한 큐로 모아 운영자가 골드 라벨을 기록하는 무빌드 정적 앱이다. 라벨 값과 수집 정책은 [docs/LLM_FILTER.md](../docs/LLM_FILTER.md#평가-데이터셋)가 기준이다.

## 동작 계약

- 서버가 같은 오리진의 `/labeling-lab`에서 제공한다. 운영자 콘솔의 `sessionStorage` 관리자 토큰만 사용하고, 없거나 만료되면 `/admin`으로 이동한다.
- `GET /api/v1/admin/music-filter-reviews`로 전체·완료·미검수 건수와 50건 단위 큐를 불러온다. 정책 검수와 곡 라벨이 모두 있어야 완료다.
- 저장은 기존 카페 범위 검수 API를 사용한다. 정책 검수는 `music_filter_reviews`, 곡 라벨은 플랫폼 원본 ID 기준 `music_track_annotations`에 upsert한다.
- 곡 라벨은 확인한 아티스트명, 체감 템포, 주요 분위기(최대 2), 사운드 구성, 리듬 특징, 보컬 유형, 선택 장르(최대 2), 메모, 사용 목적을 기록한다. 선택지는 화면에는 한국어로 표시하고 DB에는 안정적인 코드로 저장한다.
- 곡 버전과 메타데이터 충분성은 화면에서 묻지 않는다. 기존 값은 갱신 시 보존하고 새 곡 버전은 `unknown`, 새 메타데이터 충분성은 미확인 `null`로 저장한다.
- 동일한 플랫폼 원본 곡의 기존 특성 라벨은 선택된 상태로 복원하고 저장 시각을 표시한다. 매장 정책 판단은 추천곡별로 새로 선택한다.
- 보컬 유형은 `목소리 없음`, `노래 위주`, `랩·말하기 위주`, `판단 어려움`만 사용한다.
- `판단 어려움`은 같은 항목의 다른 값과 함께 선택하지 않으며, 자유 메모는 정형 선택을 보완할 때만 사용한다.
- 확인한 아티스트의 다른 곡은 운영자가 명시적으로 조회할 때 최신 라벨 최대 3건을 참고 자료로 보여준다. 자동으로 아티스트를 추정하지 않는다.
- 판단 당시 매장 정책 아래에 해당 AI 승인·거절 결과를 바로 표시한다.
- 제목에 대소문자 구분 없이 `Playlist` 또는 `플리`가 포함된 항목은 큐와 현황 집계에서 제외한다.
- `운영 참고용`과 `평가 전용`을 구분해 저장한다. 현재 라벨은 라이브 추천곡 상태, LLM 입력, 자동수락과 AI 필터 판단을 변경하지 않는다.

서버 실행 후 관리자 콘솔에 로그인하고 `/labeling-lab`에서 접근한다.
