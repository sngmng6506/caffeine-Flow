# 음악 라벨링

신청곡을 자동 라벨링한 뒤 사람이 그 결과가 곡과 맞는지만 확인하는 관리자 정적 앱이다.

- `/labeling-lab`에서 관리자 sessionStorage 토큰으로 접속한다.
- `/admin/audio-labels`에서 플랫폼·곡별 중복 제거 목록과 서버 집계를 읽는다. AI 필터 OFF·거절 곡과 Spotify 미지원 상태도 포함한다.
- 기본 보기는 자동 분석이 끝난 검토 대상만 보여준다. 대기·실패·미지원 곡은 미검토 전체/전체 보기에서 확인한다.
- `틀림 판정` 보기는 사람이 자동 라벨을 보증하지 않은 곡만 모은다. 다시 판정하면 목록에서 빠진다.

## 사람이 하는 일

두 가지만 답한다. 택소노미를 고르지 않는다.

1. 아티스트가 맞는지 — 수집한 곡을 플랫폼 검색으로 매칭하므로 엉뚱한 곡을 분석한 것을 잡을 곳이 여기뿐이다.
2. 3단 자유 서술이 곡과 맞는지 — `맞음` 또는 `틀림`. 둘은 같은 무게로 두어 한쪽으로 몰리지 않게 한다. 중간 선택지는 두지 않는다 — 판단을 미루는 칸이 되어 어느 쪽으로도 쓰지 못하는 라벨만 쌓인다.

판정은 `human_review_status`에 남고 자동 라벨 값 자체는 바뀌지 않는다. `맞음`만 라벨을 사람 라벨(`label_source='human'`)로 승격한다. `틀림`은 라벨을 보증하지 않으므로 자동 라벨로 남겨, 재분석과 재정규화가 그 곡을 계속 갱신할 수 있게 한다.

`다음`만 누르면 미검토 상태를 유지한다. 매장 정책 승인·거절 선택은 이 화면에 없다.

## 단축키

곡마다 세 번 누르는 작업이라 손이 마우스와 키보드를 오가지 않게 한다.

| 키 | 동작 |
| --- | --- |
| `1` `2` | 맞음 · 틀림 |
| `A` | 아티스트 확인 토글 |
| `←` `→` | 이전 곡 · 다음 곡 |

입력칸이나 선택 상자에 포커스가 있으면 가로채지 않는다. 자동 라벨이 없어 판정 버튼이 꺼진 곡에서는 숫자 키도 함께 막는다.

## 서술이 계속 빗나갈 때

`틀림 판정` 보기에서만 3단 프롬프트 편집기가 열린다. 개별 곡을 고치는 것이 아니라 다음부터 모든 곡에 쓸 문장을 고치는 자리다.

1. 틀린 서술들을 훑어 무엇이 빠졌는지 본다.
2. 프롬프트를 고치고 저장한다. 이미 저장된 서술은 그대로이며 다음 분석부터 적용된다.
3. `틀림 곡 전부 재분석`으로 그 곡들만 다시 큐에 넣는다.

프롬프트를 비우고 저장하면 워커가 들고 있는 기본 문장(`audio-llm-1`)으로 돌아간다. 고친 문장은 `audio_prompt_revisions`에 추가만 되고 지워지지 않으므로, 옛 서술의 `prompt_version`으로 당시 문장을 되짚을 수 있다.

MAEST 결과·임베딩·택소노미를 프롬프트에 넣지 않는다. 두 단계가 서로를 보면 앙상블이 아니라 한쪽의 복창이 된다.

## 화면에 보이는 것

- 3단 자유 서술과 분위기·악기·보컬·구성. 사람이 판단하는 유일한 근거라 넓은 단에 명조로 조판한다.
- 오른쪽 좁은 단은 참고 자료다 — MAEST 상위 스타일의 평균·최댓값과 구간 수, 음향 계측. 원본 버튼으로 전체 구간 JSON과 이력 ID를 조회한다.
- 수집한 아티스트명과 저장된 이름이 다르면 표제에 함께 보여준다. 엉뚱한 곡을 분석한 경우를 여기서 잡는다.
- 이상한 곡은 `곡 듣기`로 원래 플랫폼에서 직접 듣는다.
- 목록은 전체 매장의 신청곡을 모은 것이고 같은 곡은 한 번만 분석한다. 분석이 끝난 곡은 작업 상태를 표시하지 않는다 — 대기·실패·미지원일 때만 곡 식별자 줄에 나온다.
- `AI 음악 서술` 토글은 3단 실행 여부를 서버에 저장한다. 다음 분석부터 적용된다.
- `최신곡 수집`은 고른 소스에서 다음 구간을 훑어 분석 큐를 채운다.

## 규칙

- 분석이나 최종 라벨이 화면 조회 후 바뀌면 409로 저장을 막으며 새로고침 후 다시 검토한다.
- `새로고침`으로 워커 진행 상태를 갱신한다. Spotify는 전체 음원 자동 분석 미지원이다.
- `재시도·재분석`은 실패 또는 완료곡을 현재 모델로 다시 큐에 등록한다. 처리 중인 곡은 재등록하지 않는다.
- `현재 장르 체계 적용`은 저장된 원본으로 재정규화만 실행한다. 기존 사람 라벨은 보호한다.
- 자동 라벨의 기본 사용 목적은 평가다. 사람 확인값은 자동 분석이 덮어쓰지 않는다.

색과 타이포는 [사장님 화면 디자인 가이드](../owner/DESIGN_GUIDE.md)의 토큰을 따른다. 운영자가 같은 제품 안에서 오가는 화면이라 여기서만 다른 색 체계를 만들지 않는다.

작은 글자에 쓰는 색은 흰색·바탕·보조면 세 곳에서 4.5:1을 넘도록 가이드 값의 어두운 쪽을 쓴다. 곡 식별자는 대문자로 바꾸지 않는다 — YouTube ID는 대소문자를 구분한다.

상태·모델 계약은 [아키텍처](../docs/ARCHITECTURE.md), 입력·출력은 [API](../docs/API.md)를 따른다.
