# Music Labeling Lab

전체 카페의 AI 음악 필터 처리 이력을 한 큐로 모아 운영자가 골드 라벨을 기록하는 무빌드 정적 앱이다.

## 동작 계약

- 서버가 같은 오리진의 `/labeling-lab`에서 제공한다.
- 운영자 콘솔의 `sessionStorage` 관리자 토큰만 사용한다. 토큰이 없거나 만료되면 `/admin`으로 이동한다.
- `GET /api/v1/admin/music-filter-reviews`로 전체·완료·미검수 건수와 50건 단위 큐를 불러온다.
- 저장은 기존 카페 범위 검수 API를 사용해 `music_filter_reviews`에 추천곡당 최신 라벨 한 건을 기록한다.
- 미검수 상태에서는 AI 판단과 사유를 숨기고, 사람 라벨을 저장한 뒤 공개한다.
- 라벨은 라이브 추천곡 상태와 AI 필터 판단을 변경하지 않는다.

서버 실행 후 관리자 콘솔에 로그인하고 `/labeling-lab`에서 접근한다.
