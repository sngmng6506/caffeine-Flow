## 신청 시점 판단 검증

파이프라인(`EMOTION_LLM`: Valence/Arousal + Audio LLM, 3x10 구간)은 운영에 들어가 있고
1곡 기준 E2E 24.9초다. **검증은 하지 않았다.** 아래를 재기 전까지 이 경로의 판정 품질은
확인되지 않은 상태다.

- **구간 커버리지.** 3x10은 곡의 16%만 듣는다(186초 곡에서 30초). 4x30은 65%였다. 같은 곡에서 4x30이 잡았던 록/메탈 전환을 3x10은 8회 중 7회 놓쳤다 — [2026-09-18 실험](../audio-analysis-worker/experiments/2026-09-18-3x10-coverage-and-verdict-stability.md). E2E가 P90 22.8초로 목표까지 여유가 있어 구간을 늘릴 여지가 있다. 현재 경로에서 3x15·4x30의 지연을 다시 재야 한다.
- **판정이 서술의 악기 판독을 그대로 따른다.** trap 곡에서 로터리가 4:4로 갈렸고, 기타로 들은 4회는 전부 accept·신스로 들은 4회는 전부 reject였다. 기준선은 5:0이라 흔들리는 것은 필터가 아니라 3단 서술이다.
- **V/A 변별력.** 남은 객관 신호가 V/A뿐인데 K-pop·재즈·trap 세 곡이 모두 `중간 · 중간`으로 나왔다. 과거 21곡 측정에서도 70% 가까이가 중간 구간이었다.
- **표본.** 지금 근거는 3곡이고 전부 3분 안팎이다. 길이·플랫폼·보컬 유무가 치우쳐 있다.
- **정답.** 3단 서술이 맞는지는 사람이 들어야 안다. trap 곡의 4:4 중 어느 쪽이 맞는지 모른다.
- **타임아웃.** 3단 API 왕복에서 55초·75초 이상치를 관측했다. 사용자가 기다리는
  경로인데 현재 타임아웃은 180초이고 폴백 정책이 없다.

측정 도구(`audio-analysis-worker/benchmark_audio_llm.py`,
`server/scripts/filter-stability.js`)는 운영 큐·DB에 쓰지 않지만 **실행하면 외부 유료 API
요금이 발생한다.** 검증 전에는 기존 fail-closed와 DB 보존 계약을 바꾸지 않는다.
