# Caffeine Flow

음악 추천 및 커뮤니티 플랫폼.  
손님이 QR로 곡을 신청하고, 사장님이 수락/거절하는 구조.

## 손님
- QR 스캔 후 YouTube / SoundCloud / Spotify 링크로 신청
- 실시간 재생 중 곡 확인
- 투표, 댓글
- 카페 TOP 10 / 전체 TOP 30

## 사장님
- Google / Naver 로그인
- 신청곡 수락 / 거절 / 스킵
- 대기곡 순서 관리
- 카페 공지, 허용 플랫폼, 신청 ON/OFF
- 시간대 / 요일별 통계
- 손님용 QR 코드 생성
